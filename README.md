# 机械类2606 · 班级网站

西安交通大学文治书院机械类2606班级自建展示网站（非学校官方）。

**线上地址：** https://ysr666.github.io/2606/

纯静态网站，无数据采集、表单、用户登录及第三方分析。可以通过 GitHub Pages 免费托管。

## 本地预览

进入工程目录后运行：

```bash
python3 -m http.server 8768
```

打开 http://localhost:8768。

## 维护

- `index.html`：页面与文字。
- `styles.css`：响应式视觉设计。
- `app.js`：活动、相册数据和交互（活动信息需核验）。
- `assets/`：精选的班级照片与正式标识。

新增活动需保证文字和对应照片真实匹配。上线前请班委确认对外发布的图片授权、活动内容口径。禁止公开内部系统截图、班级通讯录、个人手机和报销凭证。

## 团日专题与 V100 数据归档

- `tuanri.html`：公开团日档案首页 / 单活动详情（例如 `tuanri.html?id=17`）
- `archive-data.js` / `archive-data.json`：从正式 V100 成果汇编整理的 32 项活动、六个篇章、对应图证和 10 个公开报道链接
- `archive-app.js` / `archive.css`：活动筛选、搜索、详情、报道跳转及相册交互
- `assets/archive/`：126 张公开展示用压缩图像，按活动关联；包括原创《向西》封面和海内外贺信世界分布图

**公开范围：** 不收录智慧团建内部截图、账目凭证、个人通讯录、个人来信原件及未经确认适合公开的资料。不把未来讲座策划当作已完成活动。完整报送材料仍以本地 V100 正式 PDF/LaTeX 工程为准，并未上传内部原件。
