# 机械类2606 · 班级网站

西安交通大学文治书院机械类2606班级自建展示网站（非学校官方）。

**线上地址：** https://ysr666.github.io/2606/

纯静态网站，无数据采集、表单、用户登录及第三方分析。可以通过 GitHub Pages 免费托管。

## 本地预览

进入工程目录后运行：

```bash
python3 -m http.server 8768
```

打开 http://localhost:8768。

## 维护

- `index.html`：页面与文字。
- `styles.css`：响应式视觉设计。
- `app.js`：活动、相册数据和交互（活动信息需核验）。
- `assets/`：精选的班级照片与正式标识。

新增活动需保证文字和对应照片真实匹配。上线前请班委确认对外发布的图片授权、活动内容口径。禁止公开内部系统截图、班级通讯录、个人手机和报销凭证。
